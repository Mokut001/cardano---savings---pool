# Cardano Community Savings Pool (DeFi Thrift System)

A real-world DeFi solution built entirely in **Haskell**, deployed on the **Cardano blockchain**, with:

- Plutus V2 Smart Contract (Haskell)
- Haskell Miso Frontend DApp
- CIP-30 Wallet Connection (Nami / Flint / Lace)
- Haskell Servant Backend API
- Vercel Deployment
- Fully open-source folder structure

This DApp solves a real-life problem: **community thrift savings** (ajo / esusu).  
It allows users to:

- Join a savings pool
- Deposit ADA into a shared contract
- Withdraw **only after the deadline**, and only by the pool owner
- Track all activity transparently on-chain
